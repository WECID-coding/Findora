NEED HELP?

Questions students usually have

The front page should answer the obvious questions before a user has to hunt through another page.

What should I include in a lost item report? +

Include a clear photo, item category, identifying details, approximate time and the most specific campus location you remember.

Can I browse without creating an account? +

This front-end demo keeps browsing open. Authentication can be added when the backend is connected to protect reports and claims.

How does a potential match work? +

A future matching service can compare category, description, location, time and image similarity. A match should be treated as a suggestion, not proof of ownership.

Is the campus map official? +

The embedded map is an interactive campus view for this page. The official MITS UniMap remains available through the external UniMap link above.
